# October 13 development retest

The October retest follow-ups are deployed to the existing development web, admin and API services. Application source: `692d0f2da537c58994a755579068cd7661f32071`.

## Changes

- Quote acceptance closes the buyer request atomically. Competing acceptances are rejected, and historical accepted requests display closed without rewriting financial history.
- A usable seller SDS is required consistently for quoting, acceptance and checkout. The seller response screen explains missing documents before submission.
- Buyer invoices download as actual PDFs with preparing and download-started feedback. Invoice access uses existing order authorization.
- Seller sales distinguish order and shipping states. Buyer orders identify shipping quotes awaiting acceptance. Tracker stages name the orders that recorded them.
- Sample destination addresses have an explicit Ship to label.
