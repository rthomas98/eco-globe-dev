## Changes

- Public browse heading follows the active category selections.
- Listing document metadata is read in one parameterized SQL batch, preserving
  per-listing ordering and viewer redaction. Anonymous listings skip that read.
- Saved delivery tracking includes a MapLibre map with recorded endpoints,
  coordinate validation, location labels, resize cleanup and a text fallback.
  It does not invent road geometry, GPS positions or delivery progress.

### Shipment API extension

`GET /api/shipments` adds nullable `originName`, `originLatitude`,
`originLongitude`, `destinationName`, `destinationLatitude`, and
`destinationLongitude`. Existing session and order/pilot participant filters
remain in force. Origin uses the explicit shipment location, falling back to
the linked order's listing location; its company must match the seller.
Destination uses only the recorded shipment destination and must match the
buyer. No default receiving site is guessed. Older responses without these
fields are supported. No database migration is required.

Map loading does not mutate shipment state. Delivery confirmation still uses
the existing PATCH operation. All existing Stripe edits were preserved.
